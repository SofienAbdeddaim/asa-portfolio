# 6. Creative concept: Living Timeline

Status: accepted

## Decision

The public site implements concept B (Living Timeline) from `docs/CONCEPTS.md`: a career timeline navigated by scroll, with a section index and the Ctrl+K palette as shortcuts.

## Consequences

Scroll-driven CSS animations instead of heavy libraries; the time axis and connectors mirror in RTL via logical properties; a plain stacked layout is the reduced-motion and no-JS baseline.
